# projects

## Overview
本目錄彙整網站內所有獨立互動式網頁應用、工具與遊戲子專案，包含 Forza Horizon 6 調教計算器（`forza-tuning-calculator`）、遊戲中心平台與 5 款遊戲（`game-center`）、賽博龐克風格音樂播放器（`music-player`）、長門櫻計畫專案展示主頁（`nagato-sakura`）、長門櫻二次元全螢幕展示頁（`nagato-sakura-nijigen`），以及擬真網頁桌面作業系統模擬器（`nagato-sakura-webos`）。

## Subdirectories & Boundaries
- `forza-tuning-calculator`: [./forza-tuning-calculator/README.md](./forza-tuning-calculator/README.md) - Forza Horizon 6 單頁通用調教計算器（v0.9.5 Beta），涵蓋車輛參數鎖定、四種風格調教計算與進階自然頻率／阻尼面板、齒比圖表與彎道三階段遙測診斷。
- `game-center`: [./game-center/README.md](./game-center/README.md) - Cyber Nexus 遊戲中心大廳與運行框架，整合 `game-center.html`、`./game-center/js/README.md` 核心前端控制器，以及 `./game-center/games/README.md` 底下 5 個遊戲與 3D 導覽子專案。
- `music-player`: [./music-player/README.md](./music-player/README.md) - 全螢幕鎖定視窗的單頁音樂播放器，支援 3D 專輯封面拖曳輪播、左側播放清單抽屜、進度條拖曳、音量控制與鍵盤快捷鍵。
- `nagato-sakura`: [./nagato-sakura/README.md](./nagato-sakura/README.md) - 長門櫻計畫專案展示主頁，結合 Sakura Genesis Canvas 入場動畫、6 個 AI 子系統 Canvas 模擬及透過 `corsproxy.io` 擷取 GitHub Social Preview 的專案展廳。
- `nagato-sakura-nijigen`: [./nagato-sakura-nijigen/README.md](./nagato-sakura-nijigen/README.md) - 長門櫻二次元風格 7 章節全螢幕展示頁，由 `./nagato-sakura-nijigen/js/README.md` 驅動 10 個 Canvas 視覺特效、點陣粒子互動與宣傳影片控制。
- `nagato-sakura-webos`: [./nagato-sakura-webos/README.md](./nagato-sakura-webos/README.md) - Nagato Sakura WebOS（Cyber Nexus）單檔網頁作業系統模擬器，實作開機序列、桌面圖示管理、視窗拖曳／縮放／貼齊、個人化與顯示設定、小工具、長門櫻 Live2D AI 助理與多種內建應用程式。
