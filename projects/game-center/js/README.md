# Game Center JS Modules

## Overview
`projects/game-center/js/` 提供遊戲中心大廳（`game-center.html`）與各子遊戲頁面共用之前端核心模組，涵蓋全螢幕入場動畫（`entrance.js`）、即時 FPS／效能浮動監控引擎（`fps-osd.js`）、集中式遊戲中繼資料集（`games-data.js`）、左側導覽欄狀態控制器（`sidebar.js`）、大廳互動與手把導覽引擎（`game-hub.js`），以及可獨立掛載的統一外圍殼層元件（`game-shell.js`，目前尚未被現有 HTML 頁面引用，各頁面改由靜態 HTML 搭配 `sidebar.js` 與 `fps-osd.js` 驅動）。

## Interface
- 入場動畫（`entrance.js`）：以 IIFE 封裝 `[entrance.js:playEntranceAnimation]`、`[entrance.js:createMatrixRain]`、`[entrance.js:createHexagons]`、`[entrance.js:createParticleBurst]`，操作 DOM `#entranceOverlay`、`#entranceMatrix`、`#entranceHexagons`、`#entranceParticles` 與 `.game-center-container`；完成或略過後設定 `[entrance.js:window.entryAnimationsCompleted]` 為 `true` 並於 `window` 派發 `animations:entryComplete` 自訂事件。
- FPS 效能 OSD（`fps-osd.js`）：對外暴露 `[fps-osd.js:window.toggleFPSMonitor]`，支援 `'fps'`、`'advanced'`（含幀延遲與折線圖）、`'full'`（含 JS Heap 記憶體、1% Low FPS 與系統時間）三種模式；內部由 `[fps-osd.js:SafeStorage]`、`[fps-osd.js:updateFPS]`、`[fps-osd.js:drawSparkline]`、`[fps-osd.js:renderOSDContent]`、`[fps-osd.js:clampOSDPosition]`、`[fps-osd.js:initOSDControls]` 驅動 `#fpsOSD`、`#osdContent`、`#fpsValue`、`#fpsOSDToggle`、`#osdSparklineAdvanced`、`#osdSparklineFull` 與 `.osd-mode-btn[data-mode]`。
- 遊戲資料集（`games-data.js`）：全域唯讀陣列 `[games-data.js:gamesData]`，定義 `cyberrace`、`snake`、`piano`、`wallclimber` 等作品之 `id`、`title`、`englishTitle`、`category`、`tags`、`inputSupport`、`banner`、`capsule`、`desc`、`publisher`、`developer`、`playtime`、`lastPlayed`、`releaseDate`、`gameUrl`、`isFavorite` 與 `gallery`。
- 側邊欄控制器（`sidebar.js`）：以 IIFE 提供 `[sidebar.js:getStoredCollapsed]`、`[sidebar.js:initSidebarControls]`、`[sidebar.js:setSidebarVisibility]`、`[sidebar.js:setSidebarCollapse]`、`[sidebar.js:toggleCollapse]`；綁定 `#gcSidebar`、`#sidebarToggle`、`#hideSidebarBtn`、`#showSidebar`、`#fpsOSDToggle` 與 `#gcBackBtn`，於 `window` 派發 `sidebarVisibilityChange`、`sidebarCollapseChange` 與 `resize` 事件，並監聽 `sidebarToggle` 事件。
- 遊戲大廳控制器（`game-hub.js`）：依賴全域 `[games-data.js:gamesData]`，於 `window` 暴露視圖與操作介面：`[game-hub.js:window.setHeroFocus]`、`[game-hub.js:window.pauseHeroAuto]`、`[game-hub.js:window.resumeHeroAuto]`、`[game-hub.js:window.startHeroAuto]`、`[game-hub.js:window.handleHeroProgressEnd]`、`[game-hub.js:window.renderHeroBanner]`、`[game-hub.js:window.selectHeroItem]`、`[game-hub.js:window.launchGameFromHero]`、`[game-hub.js:window.launchHeroDirect]`、`[game-hub.js:window.selectCategory]`、`[game-hub.js:window.filterByTag]`、`[game-hub.js:window.openGameDetailByObj]`、`[game-hub.js:window.getCurrentGameCenterView]`、`[game-hub.js:window.closeGameView]`、`[game-hub.js:window.closeDetailView]`、`[game-hub.js:window.launchGame]`、`[game-hub.js:window.closeModal]`、`[game-hub.js:window.toggleSortModal]`、`[game-hub.js:window.toggleFilterModal]`、`[game-hub.js:window.selectSortOption]`、`[game-hub.js:window.selectFilterGroupOption]`、`[game-hub.js:window.openMediaPreview]`、`[game-hub.js:window.closeMediaPreview]`、`[game-hub.js:window.toggleMediaFullscreen]`、`[game-hub.js:window.navigatePreviewMedia]`、`[game-hub.js:window.toggleCurrentFavorite]`、`[game-hub.js:window.toggleGameFavorite]`、`[game-hub.js:window.selectDetailMedia]`、`[game-hub.js:window.navigateDetailMedia]`；同時於頂層腳本作用域定義 `[game-hub.js:selectGridCard]`、`[game-hub.js:focusCardHover]`、`[game-hub.js:handleGamepadA]`、`[game-hub.js:handleGamepadB]`、`[game-hub.js:pollGamepad]`、`[game-hub.js:playSound]`、`[game-hub.js:initCityBackgroundToggle]` 與 `[game-hub.js:initGameHubUI]`。
- 統一外圍殼層（`game-shell.js`）：自注入式 IIFE 元件，經由 `[game-shell.js:bootShell]` 偵測 `[game-shell.js:isEmbedded]` 並依序執行 `[game-shell.js:ensureDependencies]`、`[game-shell.js:injectShellStyles]`、`[game-shell.js:injectShellHTML]`、`[game-shell.js:initHeaderAndSettingsController]`、`[game-shell.js:initSidebarLogic]` 與 `[game-shell.js:initFPSOSDLogic]`，暴露 `[game-shell.js:window.toggleFPSMonitor]`。

## Invariants
- 側邊欄雙鍵同步與防閃爍不變量：`[sidebar.js:getStoredCollapsed]` 與 `[sidebar.js:setSidebarCollapse]` 同時讀寫 `sidebarCollapsed` 與 `gcSidebarCollapsed`（預設為 `true` 摺疊），且於腳本執行初期立即在 `#gcSidebar` 套用 `.collapsed` 以避免載入時版面跳動；切換摺疊時若原 `<i>` 已被 Lucide 置換為 `<svg>`，會重建 `<i data-lucide="...">` 再呼叫 `window.lucide.createIcons()`。
- OSD 邊界箝制與數據採樣不變量：`[fps-osd.js:clampOSDPosition]` 與 `[fps-osd.js:getOSDBounds]` 強制將 `#fpsOSD` 限制於 `.game-center-container, .game-container` 可視區域內（保留 8px 安全邊距），並於寬度 ≥ 190px、高度 ≥ 110px 內回復尺寸；`[fps-osd.js:updateFPS]` 僅收錄 `0 < delta < 500` ms 的幀間隔（上限 200 筆）計算 1% Low FPS，而 `[fps-osd.js:drawSparkline]` 與 `[game-shell.js:initFPSOSDLogic]` 的 `drawSparkline` 在畫布寬或高為 0 時立即返回；拖曳手把皆忽略 `.osd-mode-switcher` 子節點。
- 大廳焦點、網格與輪播保護：`[game-hub.js:navigateGrid]` 固定採 4 欄網格（`cols = 4`），`[game-hub.js:applyCurrentFilters]` 將 `currentFocusedCardIndex` 箝制於 `[0, filteredGames.length - 1]`；`[game-hub.js:handleHeroProgressEnd]` 僅於 `gamesData` 非空且 `!isHeroPaused && focusArea !== 'HERO'` 時自動推進輪播；開關彈窗前呼叫 `document.activeElement.blur()` 以防止焦點殘留。
- 外圍殼層注入冪等與 iframe 隔離：`[game-shell.js:bootShell]` 偵測 `window.self !== window.top`（`isEmbedded`）時不注入導覽列、側邊欄與 OSD，僅注入 `.game-container, #gameContainer` 滿版定位樣式；`[game-shell.js:injectShellStyles]` 與 `[game-shell.js:injectShellHTML]` 分別檢查 `#gc-shell-dynamic-css` 與 `#gcSidebar` 確保單次注入。
- 全域依賴與儲存容錯：`[fps-osd.js:SafeStorage]` 與 `[game-shell.js:SafeStorage]` 以 `try...catch` 包覆 `localStorage`；各模組存取 `window.lucide`、`window.Core`、`window.Live2DManager` 及 `window.closeDetailView` 時均具備前置存在性檢查。

## Side Effects
- `localStorage` 與 `sessionStorage` 讀寫：
  - `[entrance.js:playEntranceAnimation]` 讀取 `localStorage.showEntranceAnimation`、讀取並移除 `sessionStorage.skipEntranceAnimation`，並切換 `<html>` 的 `skip-entrance-anim` 與 `no-scroll` 類別。
  - `[fps-osd.js:SafeStorage]` 讀寫 `fpsOSDActive`、`fpsOSD_left`、`fpsOSD_top`、`fpsOSD_width`、`fpsOSD_height`、`fpsOSD_mode`。
  - `[sidebar.js:initSidebarControls]` 讀寫 `showSidebar`、`sidebarCollapsed`、`gcSidebarCollapsed`，並於返回遊戲中心或重整前寫入 `sessionStorage.skipEntranceAnimation = 'true'`（必要時設定 `window.location.href` 或呼叫 `window.location.reload()`）。
  - `[game-hub.js:initCityBackgroundToggle]` 透過 `Core.storage` 讀寫 `backgroundStyle`（並將 `'city'`/`'cyber-city'` 正規化為 `'dom'`）。
  - `[game-shell.js:bootShell]` 讀寫 `headerFixed`、`theme`、`headerHeight`、`live2dEnabled`、`backgroundStyle`、`animationStrength`、`soundEnabled`、`showSidebar`、`sidebarCollapsed`、`fpsOSDActive`、`fpsOSD_left`、`fpsOSD_top`、`fpsOSD_width`、`fpsOSD_height`、`fpsOSD_mode` 及 `sessionStorage.skipEntranceAnimation`。
- DOM 變更與網路資源載入：`[entrance.js:createMatrixRain]`／`createHexagons`／`createParticleBurst` 批次建立大量動畫節點；`[game-hub.js:launchGame]` 設定 `window.location.href = targetGame.gameUrl`，`[game-hub.js:window.closeGameView]` 重設 `#game-iframe` 為 `'about:blank'`；`[game-shell.js:ensureDependencies]` 於缺少 `window.lucide` 時動態插入 `https://unpkg.com/lucide@latest` 腳本，並於 `<body>` 注入 `#gc-shell-host-container` 與 `.nav-overlay`。
- 計時器、`requestAnimationFrame` 與 Web Audio：`[entrance.js:playEntranceAnimation]` 設定 `3000ms` 與 `1500ms` `setTimeout`；`[fps-osd.js:updateFPS]` 與 `[game-shell.js:initFPSOSDLogic]` 啟動 `requestAnimationFrame` 及 `ResizeObserver`；`[game-hub.js:pollGamepad]` 以 `requestAnimationFrame` 持續輪詢手把輸入、以 `setInterval(..., 10000)` 更新 `#clock`、並以 `[game-hub.js:playSound]` 惰性建立 `AudioContext` 合成導覽／確認／返回音效；`[game-hub.js:toggleMediaFullscreen]` 呼叫 `requestFullscreen()`／`exitFullscreen()`。
