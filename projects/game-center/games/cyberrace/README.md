# cyberrace

## Overview
本目錄為 CyberRace 3D 山道賽車遊戲的應用程式根目錄，整合前端執行期遊戲網頁、核心 JavaScript 子系統、靜態車輛／賽道 JSON 資料集與離線 Python 賽道點位追蹤／視覺化編輯工具：
1. **前端入口與主引擎（`cyberrace.html`）**：提供五階段選單與遊戲畫面（模式選擇、賽道與 3D 遙測預覽、車輛選擇、AI 難度、3D 賽車主場景與 HUD／Horizon 設定覆蓋層），並透過行內 IIFE 建置 `window.Game` 主遊戲引擎，統籌 Three.js 場景、賽道取樣與捷徑交會偵測、計圈／檢查點、4 車位起跑倒數、主迴圈及完賽結算。
2. **核心 JavaScript 模組（`./js/README.md`）**：由 10 個獨立 IIFE／單例腳本構成，負責物理、車輛動力與 AI、3D 賽道／車輛／粒子建構、攝影機、手把觸覺、HUD 儀表／小地圖、選單遙測分析儀與 UI 導航。
3. **靜態資料與資源（`data/`、`css/`、`assets/`）**：包含賽道／車輛索引與個別規格 JSON（`data/tracks/*.json`、`data/cars/*.json`）、介面與遙測樣式（`css/`）及媒體圖示（`assets/`）。
4. **離線 Python 賽道製作工具**：`trace_track_to_points.py`（命令列二值化骨架追蹤、RDP 簡化、CubicSpline 精度評估與 JSON／JS 匯出）與 `track_editor_gui.py`（Tkinter 互動式底圖對齊、起終點／檢查點／捷徑繪製與 JSON 匯出 GUI）。

## Invariants
- **HTML 腳本載入順序與儲存容錯**：
  - `[cyberrace.html:localStorage fallback]`（L15–39）必須最先執行以確保瀏覽器封鎖 Storage 時降級至記憶體 `memStore`；CDN 腳本（`three.js r128`、`OrbitControls.js`、`lucide`）須先於 `./js/track-telemetry-analyzer.js` 與 `./js/physics.js`–`./js/ui-controller.js` 載入，再執行網站核心腳本及內嵌 `window.Game` 與 `[cyberrace.html:startUIWhenReady]`。
  - `[cyberrace.html:savedVib]`（L1034–1038）若偵測 `vibrationIntensity` 為 `'0.15'` 或 `null` 強制重設為 `'0.10'`；`[cyberrace.html:init]` 限制像素比上限 `Math.min(window.devicePixelRatio, 2)`，且 `[cyberrace.html:onResize]` 於容器尺寸 `<= 0` 時早退。
- **物理步長、賽道追蹤與計圈／完賽不變量**：
  - `[cyberrace.html:animate]` 單幀時間步長夾限 `dt = Math.min(clock.getDelta(), 0.05)`；僅在 `gameState === 'playing'` 更新比賽時間與物理，且跳過 `car.finished` 之車輛；玩家輪胎冒煙對非驅動輪僅於 `playerBrake >= 0.25` 觸發，發煙門檻為 `smokeIntensity >= 0.25`。
  - `[cyberrace.html:getClosestTrackInfo]` 局部搜尋視窗依 `TRACK_SAMPLES`（`2400`）縮放，若局部最短距離 `>= 40` 公尺則回退全域搜尋；`[cyberrace.html:createTrack]` 依 `selectedTrackDirection === 'reverse'` 反轉主線與支線點列，內積夾限 `[-1, 1]` 防 `Math.acos` 產生 `NaN`，支線至少取樣 `40` 點並以交會門檻與預設索引備援計算分岔／匯合點。
  - `[cyberrace.html:updateLapProgress]` 在 `circuit` 模式必須通過中段（`0.35 < currentT < 0.65`）重新武裝 `car.lapReady`，方能於跨線（`prevT > 0.80 && currentT < 0.20`）計圈（總圈數 `TOTAL_LAPS = 3`）；`linear` 模式於 `[cyberrace.html:checkFinish]` 須滿足 `raceTime > 5.0 && car.totalProgress >= 0.995` 才判定完賽；`gameMode === 'time_attack'` 時於 `[cyberrace.html:start]` 強制 `aiCount = 0`。
- **Python 賽道工具與 Schema 已知邊界約束**：
  - `[trace_track_to_points.py:trace_graph_path]` 採 8 鄰域無向圖，環路修剪上限 `100` 輪，未同時提供 `start_xy` 與 `end_xy` 時僅搜尋 `deg == 1` 端點；已知現存呼叫不一致：`[trace_track_to_points.py:__main__]`（L330）呼叫 `to_json_dict` 時漏傳 `name_ja` 參數導致 `stars`／`track_width` 錯位，且 L341 傳入 `index.json` 而非實際的 `tracks_index.json`，同時 `to_json_dict` 不會產生 `startIndex`、`finishIndex`、`checkpoints`。
  - `[track_editor_gui.py:TrackGuiEditor]` 視窗縮放夾限 `[0.15, 15.0]`、底圖縮放下限 `0.1`、`shortcuts` 至少保留 1 筆、`circuit` 模式清空並禁用 `checkpoints` 與 `finish_index`；`delete_selected_point` 僅重算主線特殊索引（未重算 `shortcuts`），而 `on_canvas_right_click` 刪除主線節點時不會同步重算任何特殊或捷徑索引；另 `[track_editor_gui.py:generate_alt_routes_data]` 直接將 `target_length_m.get()` / `downhill_height_m.get()` 字串用於浮點算術而未經 `parse_float_val` 轉換（有有效捷徑時會觸發型別錯誤）。

## Side Effects
- **DOM 變更、WebGL 渲染與網站整合**：
  - `[cyberrace.html:init]` 於 `#game-canvas-container` 建立並掛載 `THREE.WebGLRenderer`、全域 `THREE.Scene`（霧效與背景 `0x0b1217`）、`PerspectiveCamera` 與 `Clock(false)`；`[cyberrace.html:start]` 逐一移除場景子節點並重建賽道、粒子與車輛網格。
  - `[cyberrace.html:start]`、`togglePause`、`startCountdown`、`updateCountdown`（含 `void text.offsetWidth` 強制 reflow）、`showRaceResult` 與 `setTelemetryVisible` 動態修改 `#hudProgress`、`.hud-lap`、`#countdownOverlay`、`#pauseHint`、`#raceResultPanel`、`#telemetryPanel` 等 DOM。
  - 內嵌腳本於 `window` 註冊 `keydown`、`keyup`、`resize` 監聽器，於 `document` 視狀態註冊 `DOMContentLoaded`，並透過 `requestAnimationFrame`、`cancelAnimationFrame`、`setTimeout`（如 `600ms` 延遲結算、`50ms` 延遲 `onResize`）驅動生命週期。
- **網路請求（`fetch`）與瀏覽器儲存**：
  - `[cyberrace.html:ensureCarInEngine]` 請求 `./data/cars/${carKey}.json` 並合併寫入 `CAR_MODELS`；`[cyberrace.html:ensureTrackInEngine]` 委派 `loadTrackData` 或直接 `fetch('./data/tracks/${id}.json')` 寫入 `TRACKS`。
  - `[cyberrace.html:localStorage fallback]` 會寫刪 `__test_storage__` 並可能以 `Object.defineProperty` 覆寫 `window.localStorage`；`[cyberrace.html:showRaceResult]` 僅在刷新個人最佳時寫入 `cyberRacer_best_circuit_lap_*` 與 `cyberRacer_best_cp_*`；初始化區塊亦讀寫 `theme`、`sidebarCollapsed`、`gcSidebarCollapsed`、`vibrationIntensity`、`tireWearEnabled`、`telemetryVisible`、`vibrationEnabled`、`transmissionMode`。
- **Python 工具檔案系統、GUI 與背景執行緒副作用**：
  - `[trace_track_to_points.py]` 讀取底圖與索引 JSON，寫出驗證疊加 PNG（預設 `Akagi_overlay.png`）、賽道 JSON、`index.json`（若存在）及選填 `--out` JS 文字檔，並輸出多筆 stdout 紀錄。
  - `[track_editor_gui.py]` 啟動 `tk.Tk().mainloop()`、透過背景 daemon thread 執行 `auto_trace` 並以 `root.after(0, ...)` 回調主執行緒、快取裁切 `ImageTk.PhotoImage`、顯示 `messagebox`／`filedialog`，並讀寫選取之 `.json`、`.txt` 與 `tracks_index.json`。
