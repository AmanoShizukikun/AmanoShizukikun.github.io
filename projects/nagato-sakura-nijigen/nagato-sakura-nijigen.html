BACKGROUND

「長門櫻」是天野靜樹最核心的 AI 專案，以打造理想中的智能女僕為目標。她並非單一模型，而是一個結合大型語言模型 (LLM) 為推理核心、透過工具調用 (Tool Calling) 技術串接七大衍生 AI 工具的數位生命體。

從最初的簡單對話系統，到如今能夠處理影像增強、品質評估、安全偵測、自動分類等多元任務，長門櫻持續進化，朝著類通用人工智能 (AGI) 的方向邁進。

ABILITIES

能力模組
01

LLM 推理核心

CORE LANGUAGE MODEL

長門櫻的核心大腦，以大型語言模型為基礎搭建。支援 GLM4、Qwen3 等多種模型切換，負責理解使用者意圖、多輪對話、推理決策，以及統籌調度所有衍生工具。

核心架構Transformer
支援模型GLM4 / Qwen3
調用方式Tool Calling
02

影像增強引擎

IMAGE CHARM

搭載三大影像處理模型——「鏡花」專責超解析度重建、「界律」負責色彩修復與風格化、「斷律」處理去噪與銳化。三者協同運作，將低品質影像轉化為高清作品。

鏡花超解析度重建
界律色彩修復
斷律去噪銳化
03

影像品質評估

IMAGE QUALITY ASSESSMENT

無參考影像品質評估系統，能自動分析影像的清晰度、色彩準確性、構圖品質等多重維度，輸出精確的品質分數與建議。

評估方式No-Reference IQA
分析維度Multi-Dimensional
04

影像自動分類

IMAGE CLASSIFICATION

基於深度學習的影像分類系統，能快速辨識並歸類各種圖像內容，支援自訂標籤體系。用於管理大量圖片資料庫。

架構Deep CNN
自訂標籤Supported
05

詐騙簡訊偵測

SMS SECURITY CHECKER

基於自然語言處理的安全防護模組，能即時分析簡訊內容，辨識詐騙模式、釣魚連結與惡意攻擊。

偵測率High Accuracy
即時分析Real-time
06

Discord 社群機器人

DISCORD BOT INTERFACE

長門櫻的社群互動介面，部署於 Discord 平台。支援文字對話、語音通話、音樂播放等多功能交互。

文字對話Enabled
語音通話Enabled
音樂播放Enabled
07

影像品質提升

IMAGE QUALITY ENHANCER

專為影像最終輸出階段設計的品質提升引擎，針對已處理的影像進行精細化調整，確保每一張作品都達到最佳視覺效果。

處理方式Post-Processing
輸出品質Production Grade
